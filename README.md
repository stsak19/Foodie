<h1 align="center">foodie</h1>

<p align="center">Καθημερινό πρόγραμμα διατροφής για recomp — 4 γεύματα, 2.490 kcal, 154γρ πρωτεΐνη.</p>

---

## Τι κάνει

| Καρτέλα | |
|---|---|
| **Σήμερα** | Τα 4 γεύματα της μέρας με τις ώρες τους. Τσεκάρεις όσα έφαγες και βλέπεις θερμίδες και μακροθρεπτικά σε πραγματικό χρόνο. |
| **Εβδομάδα** | Και οι εφτά μέρες με τα σύνολά τους. Πάτα μια για να δεις τα γεύματα. |
| **Πρόοδος** | Βάρος κάθε πρωί, μέση μια φορά τη βδομάδα. Υπολογίζει εβδομαδιαίο μέσο όρο, διαφορά και γράφημα 4 εβδομάδων. |
| **Οδηγός** | Στόχοι, παραλλαγές κάθε γεύματος και οι κανόνες προσαρμογής. |

Κάθε γεύμα έχει **παραλλαγές** — τα σύνολα της μέρας ενημερώνονται αυτόματα.

## Εγκατάσταση στο κινητό

Άνοιξε τη σελίδα και πρόσθεσέ τη στην αρχική οθόνη:

- **iPhone** — Safari → Κοινή χρήση → *Προσθήκη στην οθόνη Αφετηρίας*
- **Android** — Chrome → ⋮ → *Προσθήκη στην αρχική οθόνη*

Ανοίγει σε πλήρη οθόνη, χωρίς μπάρα διεύθυνσης.

## Πώς αποθηκεύονται τα δεδομένα

Στη συσκευή, μέσω `localStorage` — δεν φεύγει τίποτα από το κινητό σου και δεν υπάρχει λογαριασμός ή server.
Αν καθαρίσεις τα δεδομένα του browser, χάνονται.

## Προσαρμογή

Όλα τα φαγητά και τα νούμερα είναι στην αρχή του `<script>` στο `index.html`:
`B` πρωινό, `S` σνακ, `MAIN` τα κυρίως ανά μέρα, `DIN` τα βραδινά, `VARS` οι παραλλαγές.
Άλλαξε τιμές εκεί και η εφαρμογή ενημερώνεται μόνη της.

Οι θερμίδες είναι εκτιμήσεις. Δεν αντικαθιστά διαιτολόγο ή γιατρό.
