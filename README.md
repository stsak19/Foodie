<h1 align="center">foodie</h1>

<p align="center">Ημερολόγιο διατροφής για recomp — στόχος 2.000 kcal και 155γρ πρωτεΐνη, με συνταγές και λίστα ψώνιων.</p>

---

## Τι κάνει

| Καρτέλα | |
|---|---|
| **Πρόοδος** | Πρωινό ζύγισμα, ημερολόγιο μήνα με χρώμα ανά μέρα, μέσος όρος βδομάδας, γράφημα 4 εβδομάδων και ισοζύγιο 7 ημερών. |
| **Σήμερα** | Πρωινό, Σνακ, Μεσημεριανό, Βραδινό. Προσθέτεις ό,τι έφαγες και βλέπεις θερμίδες και μακροθρεπτικά. Από κάτω γράφεις τις θερμίδες του Apple Watch (οι ηρεμίας είναι στάνταρ 1.800) και βγαίνει το ισοζύγιο της μέρας. |
| **Συνταγές** | Όλες οι συνταγές ανά γεύμα, με υλικά, βήματα και χρόνο. |
| **Στόχος** | Θερμίδες και πρωτεΐνη ημέρας. Αλλάζουν από εδώ. |
| **Ψώνια** | Το καλαθάκι πάνω δεξιά. Λίστα της βδομάδας με τιμές. |

Η μπάρα με τις 7 μέρες πάνω στο Σήμερα ανοίγει όποια μέρα θες. Η σημερινή είναι πορτοκαλί.

## Εγκατάσταση στο κινητό

Άνοιξε τη σελίδα και πρόσθεσέ τη στην αρχική οθόνη:

- **iPhone** — Safari → Κοινή χρήση → *Προσθήκη στην οθόνη Αφετηρίας*
- **Android** — Chrome → ⋮ → *Προσθήκη στην αρχική οθόνη*

Ανοίγει σε πλήρη οθόνη, χωρίς μπάρα διεύθυνσης.

## Πώς αποθηκεύονται τα δεδομένα

Όταν τρέχει ως Claude artifact, τα δεδομένα συγχρονίζονται σε όλες τις συσκευές.
Όταν ανοίγεις το `index.html` αλλού, αποθηκεύονται στη συσκευή μέσω `localStorage` και χάνονται αν καθαρίσεις τα δεδομένα του browser.

## Δομή

```
index.html              η εφαρμογή — μία σελίδα, μηδέν εξαρτήσεις
manifest.webmanifest    ρυθμίσεις PWA
logo.png                το λογότυπο στην κεφαλίδα
icon.svg                το λογότυπο
icon-192/512/180.png    εικονίδια
favicon.ico
```

## Προσαρμογή

Όλα τα δεδομένα είναι στην αρχή του `<script>` στο `index.html`:
`FOODS` τα φαγητά (θερμίδες, μακροθρεπτικά, σε ποιο γεύμα ανήκουν), `RECIPES` οι συνταγές, `SHOP` η λίστα ψώνιων, `REST_STD` οι θερμίδες ηρεμίας.
Ο στόχος αλλάζει από την καρτέλα Στόχος.
